# Home Assistant App: Bitwarden lite

The official [Bitwarden](https://bitwarden.com) server, in its single-container
[lite deployment](https://bitwarden.com/help/install-and-deploy-lite/), as a
Home Assistant app. Optional built-in Cloudflare Tunnel and Tailscale
Serve/Funnel publish it over HTTPS without opening ports.

Supports `aarch64` (Home Assistant Green, Yellow, Raspberry Pi 4/5) and `amd64`.

See [DOCS.md](DOCS.md) for setup.
